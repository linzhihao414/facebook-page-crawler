# Facebook Page Crawler

Search Facebook by keywords, collect public page info, export to Excel.

## Quick Start

1. Edit `keywords.txt` with your search terms
2. Double-click `run.bat`
3. Login to Facebook when browser opens
4. Results saved in `导出结果/` folder

## What it collects

- Page name
- Page URL
- About / description

Requires Facebook login (scan QR or manual login in browser).
